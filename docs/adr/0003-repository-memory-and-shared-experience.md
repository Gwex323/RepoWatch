# 分开保存仓库记忆与跨仓库共享经验

用户需要复用同仓库与跨仓库的相似问题经验，同时接受完整上下文按项目保留。仓库原始代码、日志和完整历史默认归属于各自仓库，跨仓库复用经过提炼和去敏的问题特征、修复方法与验证经验；复用后必须在当前仓库重新验证。这保留跨项目学习能力，并避免将其他仓库的上下文和成功结论直接当作当前修复的依据。

修复通过验证和独立审查后自动提炼经验；失败尝试单独标为失败经验，不能充当已验证方案。用户可查看、纠错、禁用和删除经验。

记忆的代码验证状态与 PR 接受／合并分别记录。后续 CI／评审证据推翻修复结论时，关联成功经验停止复用并待复核；返修通过后更新。语义编辑不自动继承旧验证，禁用／删除影响未来检索与注入，原任务审计产物有独立留存范围；详见[实施契约](../implementation-contracts.md)。
