# 导入全仓扫描完成后才能自动修复

用户要求每次导入都完成全仓深度扫描。系统以明确代码版本、覆盖清单、逐模块审查记录、适用检查基线和已发现候选的证据作为完成门槛，完成后该仓库才可进入自动修复。按 Q36 细化，可恢复缺口在原预算和授权内先自动补全，无法恢复或耗尽上限才保留“扫描未完成”状态并暂停队列，等待用户处理；仍接受较长的导入等待时间，不采用先修复已有 Issue、后补齐扫描的方式。

用户选中的本地缺陷候选同样受当前目标分支扫描就绪门槛约束，不能由另一入口绕过；扫描未完成前可保存待处理任务。版本漂移与调度见[实施契约](../implementation-contracts.md)。
