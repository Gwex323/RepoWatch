# 采用 LangGraph 与 Deep Agents 执行底座

用户选择 LangGraph 承载明确阶段、检查点与暂停恢复，Deep Agents 承载任务内模型和工具循环，以复用同一技术体系中的可恢复流程与 Agent 能力，并接受适配和集成成本。应用仍实现业务调度、扫描覆盖、验收、幂等发布与沙箱；不依赖托管 MDA，不把框架 checkpoint 当成远程副作用恰好一次保证。

实际角色的必需模型能力在运行前核验，运行保持配置快照。瞬时错误有限重试，必需能力不兼容、持续错误或额度／预算耗尽时全局暂停，默认不跨供应商自动切换，由用户处理后恢复。
