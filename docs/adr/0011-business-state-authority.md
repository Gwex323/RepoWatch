# 业务数据库与运行检查点分层管理

仓库、扫描批次、业务任务、任务运行和 PR 分别管理自身状态，以业务数据库记录作为对外权威；LangGraph 检查点仅负责运行内部进度与上下文。用户接受恢复时核对业务记录、检查点和实际产物的成本，以避免把图执行位置直接当成业务验收或交付结果；证据绑定代码版本，修改后重新验证。

正常等待／图中断与异常遗留运行分开记录；重启时不能仅凭 checkpoint 或开放 PR 判定崩溃。内容版本、阶段意图、产物摘要与恢复核对的实施细节见[实施契约](../implementation-contracts.md)。
