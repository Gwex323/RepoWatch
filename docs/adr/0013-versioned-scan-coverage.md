# 以版本化覆盖账本管理扫描与续扫

用户选择由程序建立固定代码版本的模块清单、检查基线与覆盖账本，并在证据齐全后核验扫描完成。同版本允许断点续扫，代码变化后旧结论过期并补扫受影响范围，影响无法可靠界定时全仓重扫；每次重新导入仍完整扫描。这接受影响判定与覆盖管理成本，避免每次分支变化都无条件重扫，也避免沿用过期结论。

Q36 进一步允许在原预算和授权内自动补齐可恢复缺口：补扫、拆分重试、重跑真实检查及重建受管环境。补全后重新核验，无法恢复或耗尽上限才转入全局阻塞；证据门槛和阻塞后的人工恢复规则不变。

批次固定 SHA 不变，目标分支变化建立新批次并逐项关联新检查或可复用覆盖依据；修复任务需要前置补扫时释放执行位，不能持有唯一执行位等待扫描。PR 未合并修改由任务验证覆盖；详见[实施契约](../implementation-contracts.md)。
