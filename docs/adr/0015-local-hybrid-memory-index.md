# 本地混合记忆检索使用可重建索引

用户选择以业务记忆记录为事实源，结合结构过滤、FTS5 关键词和 sqlite-vec 语义候选，使用本地 CPU embedding，接受模型资产、索引同步和融合排序的集成成本。索引可重建，删除或禁用影响新检索；语义未就绪时明确降级到关键词／结构检索，仍保持当前仓库的独立验证门槛。具体编码模型由许可证和召回实验确定。

事实更新与待索引事件同事务保存，命中后核验内容／索引配置版本；删除和禁用先在事实源生效，不等待索引清理。恢复执行时重建记忆注入，不能绕过状态检查使用旧缓存。生命周期细节见[实施契约](../implementation-contracts.md)。
