# 历史记录索引

这里仅建立导航，不搬移既有成果，不默认读取全部历史。需要追溯时，先在下面选定来源中搜索相关主题，再读命中段及必要上下文；当前状态见 [NOW](../NOW.md)，当前规则见 [项目索引](../../../PROJECT_INDEX.md)。

| 追溯目的 | 原位来源及边界 |
| --- | --- |
| 查 Q1—Q36、后续巡检调整和当时交付 | [访谈历史](../../design-discovery.md)，按问题编号／关键词定位；当前要求以基线和契约为准 |
| 查文档一致性复核的修订原因和当时范围 | [文档复核](../../document-review.md)；既有检查计数不自动覆盖后续新增文件 |
| 查相关项目实现、许可证和固定源码版本 | [项目对比](../../research/project-comparison.md) 与 [快照](../../research/repository-snapshots.json)；2026-11-02 调研证据，不能冒充最新上游事实或已安装依赖 |
| 查后续已完成的 OpenSpec 变更 | [OpenSpec 归档位置](../../../openspec/changes/archive/)；本轮核验仅占位，活动规划不属于历史归档 |

已接受 ADR 和文件名含 discussion／proposal 的当前设计仍可能是有效依据，不能仅凭文件名视为过期历史；按 [项目索引](../../../PROJECT_INDEX.md) 确认职责。

仅当旧过程有追溯价值且任务允许时，保存简短背景、决定变化、结果及证据链接，并更新本页；当前状态原位修订。不要存完整对话、工具流水账、秘密或个人设备私有路径。不删除或搬移已有文件来“整理历史”。
