# P1 暂停、命令生命周期与恢复

日期：2026-11-04。本页记录正式控制与恢复端口；产品规则见[执行权与暂停](../implementation-contracts.md#执行权与暂停)，阶段进度见 [tasks](../../openspec/changes/build-github-issue-agent-harness/tasks.md)。

## 暂停、取消与显式恢复（2.5）

`ControlService` 提供带操作标识、预期修订及本地用户身份的全局／仓库暂停、取消、逐项处理阻塞及显式恢复。重复同内容回读原结果，过期或同标识不同内容拒绝；暂停在安全边界请求停止，原命令和未核销步骤继续占用执行位。取消沿用主任务持久标记与预算归属规则，不解除全局阻塞。

恢复前核对唯一执行位、遗留运行、命令实际停止证明、远端未知写入、全部未解决原因及适用预算。处理某个原因和恢复是两次明确操作，不提供强制通过。无进展／振荡及其他需重试障碍要求具体步骤、可观察目标和有限尝试／工具步数／有效时长；方案写入新配置修订，原尝试历史保留。授权只在配置匹配的下次领取时消费一次，运行引擎仍须执行对应有界窗口，不能提前认定重试验证通过。

## 实际命令监督

`CommandSupervisor` 是受信任宿主命令适配，使用 Windows 作业对象跟踪整棵进程树，保存命令标识、PID／创建身份、期限及停止证明。流程为持久意图 → 受信任启动器等待管道 → 加入作业 → 身份落库 → 打开启动门。数据库或绑定失败不会启动实际命令；不继承模型／控制凭据环境，参数摘要用于审计。

关闭最后一个作业句柄会终止其中进程；控制进程崩溃后，新实例按作业和 PID 创建身份复核，避免把复用的 PID 当原命令。父进程退出不能替代子进程停止；仅作业活动数为零或作业不存在且旧身份已结束，才登记可回读的停止证明。超时停止及结果持久化，无法证明时保持占位。

这个适配只供宿主受控组件和测试夹具使用，不向 Agent 提供宿主任意终端；仓库代码默认容器执行的接入仍由 P2 完成。Windows 实测不代表 Linux／WSL 宿主适配、完整安装启停或容器隔离已经验收。

## 异常对账与显式放弃旧运行（2.6）

`RecoveryService` 在启动时核对业务运行、执行位、Worker 进程创建身份、命令停止证明、预算意图、远端操作、阶段结果、显式 checkpoint 引用和产物实际摘要。正常 PR 等待及其他仍健康的 Worker 不误报为崩溃；checkpoint 单独领先业务事实不能作为阶段完成。对账不会重放模型、命令或未知远端写入。

显式放弃绑定新鲜报告摘要及幂等人工操作。仍在执行的模型请求或未停命令拒绝释放；已确认 Worker 退出时，已发出请求保留未知用量占用，未发出预留可释放。旧租约内未核实有效时间保守占用，不将停机时间记作实际用量；缺失租约边界时保守占用剩余额度。操作保持全局暂停和任务阻塞，不能覆盖新执行位。

正式父子运行共用根租约，报告聚合全部后代的命令、预算预留、产物及阶段；健康子运行不误报崩溃，显式放弃根运行覆盖后代且只核销一次。中途有意预算等待可安全挂起，但未完成业务确认的阶段不因此获得可复用检查点资格。

2026-11-04，`test_recovery.py` 与控制回归合计 14 项通过，包含真实 checkpoint 的正常等待、报告过期、未知远端写入、活跃请求拒绝放弃及实际 Worker 异常退出后的未知预算占用。这是 E18 的内核切片，完整产品重启链路仍待集成。

## 有界诊断（2.7）

`DiagnosticService` 将本地用户指定测试、已保存配置引用、独立有限预算和期限原子保存，不因保存调用模型。系统诊断无需导入仓库，不构造虚假仓库或 SHA；运行快照明确标为 `system_diagnostic`，准入修订记录诊断权限策略。

诊断只能显式领取，在旧运行／命令核实停止后独占执行位；普通队列不会领取。权限按测试类型限定为受控存储工具或供应商模型测试，不能发布、修改源码或转成业务任务。未知远端操作保持冻结，允许只读测试排障。取消及期限阻止新步骤；结果保存受限核验事实，角色核验另登记宿主产物。诊断结束不修改原业务预算、阻塞或暂停。正式 Worker 已接入连接／角色／存储处理器，[控制台](local-control.md)提供显式入口；过期排队授权直接结束，不创建伪 Run。

2026-11-04，`test_diagnostics.py` 的 6 项诊断测试与已有数据升级测试合计 7 项通过；存储／控制／恢复回归另有 24 项通过。迁移重建任务表时保留 CHECK、来源唯一性、任务预算不可转移及既有 PR 外键，提交前执行外键检查。
