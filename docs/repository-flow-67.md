# 仓库六阶段处理页面（Issue #67）

## 页面职责

1. 环境准备：下载、运行选项、依赖/测试/访问、诊断、命令配置、日志与巡检。
2. 项目分析：模型状态、报告、来源与限制、范围验收、重试和恢复。
3. Issue：同步远程问题、选题并发起分析；提交后切换到项目分析。
4. 复现结果：问题依据、复现步骤、人工反馈和旧问题处置。
5. 修复：补丁、验证、独立审查、修复重试与历史。
6. PR：发布结果、远程链接、发布失败与仅重试发布；不推断远程合并状态。

源码版本选择为共享上下文。分析与复现共用一个分析服务实例及记录选择，隐藏分区保留草稿；修复和 PR 共用一次任务轮询。前后步骤按钮仅导航，不执行任务。初次进入环境准备；从待办进入时优先复现结果。下载、诊断和巡检不再出现于分析/Issue/修复/PR 子页。

## Review

静态自审检查源版本与分析选择、组件边界、轮询与清理、表单保留、空状态、历史记录、原权限/确认门槛和发布重试。发布失败后的队列记录依 context.publication_retries 继续归入 PR 页，避免 stage 清空后消失。PR 页区分等待发布、正在发布、发布未完成和已创建，不声称已合并。

## 验证

TypeScript/Vite 构建与 git diff --check 通过。Playwright 在 1920、1440、390px 三种宽度通过，覆盖原设置入口及六阶段导航、内容隔离、Issue 跳转、报告恢复、人工确认请求字段、发布重试与重排队展示、配置和复现草稿、巡检、无溢出和页面错误。已检查 PR 桌面截图与环境准备手机截图。接口为模拟响应，未调用真实模型、发布目标仓库内容或修改生产数据库；本次未运行全部历史浏览器测试或后端测试。
