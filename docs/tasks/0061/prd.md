# 最终审查自动恢复闭环

关联 Issue #61 / PR #62。用户要求在报告校验、超时等可恢复故障后，由系统自动续办。

## 要求

- R1：JSON 语法错误提供固定类别、位置和行列；字段错误仅使用可信 schema 字段及固定原因。诊断进入当前纠正与检查点续办输入，不记录失败正文。
- R2：仅有效检查点支持最终审查自动续办。原读取、交接和源码证据保持，模型实际运行独立审查员，工具关闭。
- R3：最多两次续办，10/30 秒退避；累计最多 32 次模型请求、1800 秒。原格式、证据、超时、输出等纠正次数跨自动续办、重启及人工 retry 不清零。
- R4：源码、执行、Issue、范围、模型、账号或流程状态不匹配时停止。拒绝、权限、协议、鉴权和未知错误不自动恢复。
- R5：调度、领任务、累计请求预占和结果保存受事务及运行版本保护；退避不阻塞其他分析任务。只读页面展示累计额度、待续办和停止原因。
- R6：旧失败任务不批量重排；新运行及显式 retry 才加入恢复链。不得保存不合格报告，不能据恢复成功自动授权修复或发布。

## 验收边界

本轮仅静态检查、语法检查和前端构建。未要求新增或执行测试、真实模型及部署；不得将静态检查当作完整运行验收。
