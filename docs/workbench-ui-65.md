# 工作台页面整理（#65）

## 变更与设计

首页以待办和下一步为主，技术角色说明移到系统信息。仓库列表与详情分开，详情按已有 Issue、分析与修复、运行环境、定时巡检组织。设置按模型、账号、自动修复和系统信息分区；供应商导入与五角色分配保留独立入口。验收明细、独立模型配置、日志和知识使用统计默认折叠。

切换分区使用 hidden 保留挂载和表单草稿；全局 hidden 样式避免旧 display 样式覆盖。已有 Issue 提交后自动切换分析区，来自问题列表的任务直接打开分析。模型、修复与账号的错误提示更新为新的菜单路径。响应式导航、返回入口、空状态、页面说明与可见焦点统一。
