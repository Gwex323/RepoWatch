# Spec Delta

## Purpose

确保 RepoWatch 自身修复在符合远程合并与部署授权后准确发布，明确绑定代码、前端资源、数据库和启动配置，并在服务不可用时由独立监护执行受控恢复，使故障记录和原任务能在重启后继续保持可信状态。

## ADDED Requirements

### Requirement: 合并与部署分别受授权约束

系统 MUST 仅在对应 PR 已通过必要审查、验证及仓库保护规则且合并权限满足时执行 GitHub 合并；部署须单独满足授权策略，并使用已确认合并的提交。不得绕过 PR 本地合并到主干或直接推送主干。

#### Scenario: 仅授权生成修复 PR
- **WHEN** PR 已准备完成但没有合并或部署授权
- **THEN** 展示待授权状态及具体拟执行动作，保留全部可审阅结果，不执行合并或部署

#### Scenario: 满足预先授权的发布规则
- **WHEN** PR 审查、验证、保护规则及自动合并部署策略均满足
- **THEN** 系统可自动通过 GitHub 合并并部署已确认的合并提交，保留每个动作回执

### Requirement: 版本清单决定实际启动内容

系统 SHALL 为每次部署记录代码绝对路径、提交、前端资源标识、解释器、数据库路径、启动入口与非敏感配置引用；启动和重启必须使用选定清单，检测到旧目录、前后端不一致或数据库错配时不得报告部署成功。

#### Scenario: 当前目录仍是旧分支
- **WHEN** 操作终端位于旧代码目录，但已选定的新部署清单指向另一目录
- **THEN** 重启严格加载清单中的代码与前端，既不跟随终端目录也不静默选择其他端口

#### Scenario: 前端资源不匹配
- **WHEN** 服务可访问但实际返回的资源标识与待发布版本不同
- **THEN** 发布验证失败并显示期望与实际版本，不能仅凭 HTTP 200 判定成功

### Requirement: 重启保留数据与安全配置

系统 SHALL 在发布前检查进行中任务并按策略排空或检查点暂停，备份数据并核验迁移兼容性；重启后使用同一明确数据库与凭据存储，恢复已授权的 Langfuse 等启动配置，且不得输出凭据或重置任务额度。

#### Scenario: 新版本启用原数据库
- **WHEN** 原工作台已有供应商、账号、故障与任务记录
- **THEN** 新进程继续读取这些数据和配置，不创建意外空数据库；原累计预算保持不变

#### Scenario: 启动配置不完整
- **WHEN** 清单要求的数据库或安全配置引用缺失
- **THEN** 启动前阻止切换并说明缺失配置，不静默丢弃监控配置或覆盖现有密钥

### Requirement: 独立监护提供有界服务恢复

系统 SHALL 由不依赖 Web 服务事件循环或模型可用性的监护组件检查服务进程、就绪状态和部署身份；仅能恢复明确属于当前工作台的进程，记录重启次数和结果，超过限制停止并通知，不能终止端口上的无关进程。

#### Scenario: Web 进程退出且模型服务不可用
- **WHEN** 工作台进程意外退出且所有模型路由不可达
- **THEN** 监护仍按有效清单执行有界重启，保留服务故障记录，待本地台账恢复后补交事件

#### Scenario: 端口被无关进程占用
- **WHEN** 目标端口已由无法匹配部署清单的进程占用
- **THEN** 监护记录冲突并停止接管，不杀死该进程或另开端口伪装原工作台恢复

### Requirement: 验证失败可以受控回滚

系统 SHALL 验证新进程的部署身份、前端资源、原数据库绑定和受影响流程；失败时按发布策略回滚到最近可用版本。数据库存在不向后兼容变更或发布后新写入时，禁止盲目覆盖数据备份，须停止并明确受阻原因。

#### Scenario: 新版本健康验证失败
- **WHEN** 新部署无法就绪且数据仍兼容上一可用版本
- **THEN** 恢复上一版本清单并验证服务，保存本次失败与回滚结果，不显示原缺陷修复成功

#### Scenario: 自动恢复原任务
- **WHEN** 新版部署完成且原故障检查通过，原任务权限、依据和预算仍有效
- **THEN** 按有效检查点继续原任务；依据过期或预算耗尽时保留受阻状态，不以部署为由自动重置

#### Scenario: 原步骤成功验证关联旧工作台版本
- **WHEN** 精确部署授权允许续办，原 retry 同事务记录对应出现项、来源任务和新版工作台摘要，随后原来源实际验证成功
- **THEN** 仅在已部署且仍待原任务验证、授权及账号仍有效、来源尝试更新且证据时间晚于该记录时，允许关联旧工作台版本的对应故障；仓库、环境、源码 revision 和实际模型绑定仍须相同

#### Scenario: 无关版本或撤权后不得解决旧故障
- **WHEN** 成功事件来自其他工作台版本、任务、旧尝试、旧时间，或对应部署续办授权已撤销
- **THEN** 保留原故障未恢复状态；不以发布回执或单独版本变化替代真实来源验证
