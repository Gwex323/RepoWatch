# Spec Delta

## Purpose

让 RepoWatch 在已有工作流的权限和事实依据内自动处理可恢复故障，统一限制重复执行、请求额度和恢复时限，并以原失败步骤的验证结果决定是否续办，避免靠重置预算或绕过验收推进任务。

## ADDED Requirements

### Requirement: 恢复动作必须经过明确策略

系统 SHALL 依据故障类别、当前任务状态、授权、执行结果和预算决定允许的恢复动作；未知问题进入诊断，取消、权限不足及依据变化分别保留明确状态，不得当作普通瞬时错误无限重试。

#### Scenario: 可恢复的超时
- **WHEN** 当前请求超时且任务仍获授权、检查点有效、预算尚有余量
- **THEN** 系统按已配置策略退避重试或续办，记录采用的等待期限与预算；不保证外部供应商必然恢复

#### Scenario: 用户已取消
- **WHEN** 故障发生后用户取消原任务
- **THEN** 待执行恢复被撤销，后续调度不得重新启动任务

### Requirement: 安全处理多条任务范围登记调用

系统 SHALL 对允许的任务范围登记批次先完整校验，再按原顺序执行并返回实际结果；批次包含其他工具、超量、非法参数或矛盾验收项时不得执行部分内容或丢弃条目，须有界纠正或记录受阻。

#### Scenario: 两条合法登记调用
- **WHEN** 一次响应包含两条允许数量内的任务范围登记调用，参数均有效且验收项不矛盾
- **THEN** 两条调用的有效条目均按顺序登记，记录真实执行结果并完成前置要求，不再仅因调用数量为二而停止

#### Scenario: 同批次存在非法或冲突条目
- **WHEN** 两条调用中一条无效或同一验收项包含冲突要求
- **THEN** 执行前拒绝整个批次，保留合法字段与原始任务约束进行定向纠正，不缩减范围换取通过

#### Scenario: 校验期间任务范围被其他任务更新
- **WHEN** 批次即将提交时发现任务范围版本已变化
- **THEN** 本批次不提交，重新核对最新范围，不覆盖其他任务已登记内容

### Requirement: 执行与发布幂等

系统 MUST 为恢复动作保留稳定身份和执行回执，并对同一根任务同时只允许一个恢复执行者；结果未知的外部动作须先核对远程状态，禁止直接重复发布 Issue、PR 或提交。

#### Scenario: 两个恢复器同时接管
- **WHEN** 原工作流恢复器和中央恢复器同时发现同一失败
- **THEN** 只有一个获得执行权，另一方读取同一动作的状态，不额外调用模型或执行工具

#### Scenario: 发布成功后回执写入前中断
- **WHEN** 远程 Issue 已创建但本地尚未确认时服务中断
- **THEN** 恢复后先查找对应远程内容并补齐回执，确认不存在后才能重新创建

### Requirement: 所有恢复共享持久化预算

系统 SHALL 对同一根任务累计各层请求、纠正、续办、耗时和已知费用，调度诊断也须纳入受限预算；重启、转交角色或生成子任务不得清零既有用量。额度不足须标记受阻并说明原因。

#### Scenario: 重启后继续处理
- **WHEN** 已使用两次恢复机会的任务在服务重启后再次被接管
- **THEN** 继续使用累计计数，仅可消费剩余机会

#### Scenario: 请求额度耗尽
- **WHEN** 诊断或恢复前发现根任务请求额度已用完
- **THEN** 不发起新的模型请求，记录已用量与停止原因；新增预算必须符合已有授权策略

### Requirement: 检查点与依据保持一致

系统 SHALL 在恢复前校验源码、任务范围、模型配置、账号授权和原任务状态；仅复用同一有效依据下的已完成证据。依据发生变化时须终止旧恢复或创建显式关联的新任务，不得伪装成同一次无损续办。

#### Scenario: 使用原证据续办审查
- **WHEN** 独立审查失败但源码、范围、模型与授权均未改变
- **THEN** 复用已完成的有效读取和交接，从可验证检查点续办

#### Scenario: 模型配置被用户修改
- **WHEN** 恢复前模型路由或配置版本改变
- **THEN** 标记旧恢复依据失效，按明确的模型变更授权建立后续任务，并保留历史和累计预算关联

### Requirement: 恢复结果必须验证后续办

系统 SHALL 区分动作执行成功与原故障解除；只有原失败检查或等价验收通过，才将出现记录标记已恢复并推进对应流程。审查拒绝须保留原结论并反馈修复，不得由调度器修改审查结果。

#### Scenario: 修复后再次审查
- **WHEN** 补丁被独立审查拒绝且仍在授权与预算范围内
- **THEN** 将具体审查反馈交回修复角色，重新验证并独立审查，通过后才能继续发布

#### Scenario: 请求已返回但证据校验未通过
- **WHEN** 超时重试获得响应，但响应未通过源码证据校验
- **THEN** 不宣称原任务完成，更新后续故障和恢复状态，保留两次结果关联
